KINSURE, kullanıcıların sigorta müşterilerini, ürün türlerini, poliçeleri ve hasar
dosyalarını yönetmesini sağlayan web tabanlı bir sigorta yönetim uygulamasıdır.
Türkçe arayüzü, kullanıcı kaydı ve girişi ile yetkilendirilmiş CRUD işlemleri sunar.

Kullanılan Teknolojiler
- Frontend: Angular 20, TypeScript, RxJS, HTML ve SCSS
- Backend: Python, FastAPI ve Pydantic
- Veritabanı: Oracle Database 23c Free
- Veritabanı bağlantısı: python-oracledb
- Kimlik doğrulama: JWT; parola güvenliği için Argon2
- Konteyner ve dağıtım: Docker, Docker Compose ve Nginx
